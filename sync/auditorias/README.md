# Auditorías de calidad

Deja aquí (un archivo por auditoría, `.md` o `.txt`, con la fecha en el nombre: `2026-10-20_auditoria.md`)
las auditorías o escuchas que el equipo de calidad quiera sumar a los hallazgos de la semana.

La tarea programada las lee en la corrida de la tarde junto con las observaciones de 🔰FEEDBACK y las
usa para encontrar manías, malas prácticas, malas costumbres, buenas prácticas y técnicas nuevas
(`sync/hallazgos_cache.json` → ⚙️ → 🔎 Ver hallazgos en la página).
